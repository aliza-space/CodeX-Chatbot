# Knowledge Base Index — Coders' Club GPREC and CodeX 4.0

**Category:** index
**Last updated:** 2026-09-20
**Tags:** index, ingestion, metadata

## Details
This knowledge base contains the official information about Coders' Club of G. Pulla Reddy Engineering College (GPREC), Kurnool, and about CodeX 4.0, the flagship coding event of Coders' Club scheduled for 24 September 2026.

Every file starts with a metadata block containing Category, Date and Tags. The ingestion script can parse these three lines into chunk metadata for filtering. Each file is split into sections with "##" headings, and every section is written to make sense on its own.

## Folder layout
- about/ contains files about Coders' Club, its websites, and GPREC.
- events/ contains files about CodeX 4.0, detailed reports of past events (CodeX 2.0, CodeX 3.0, Code Symposium 2K24 and 2K26, Galactic Gamble, IdeaSprint, OUTSYSLAYER, Nexus 2K25), the past winners table and the sponsors history.
- team/ contains the Coders' Club convener, four faculty coordinators, contact persons, all 49 student coordinators with their branches, and student organizing teams.
- resources/ contains the learning activities offered by Coders' Club.
- faqs/ contains question and answer pairs.
- rules/ contains the CodeX 4.0 rules, refund policy and disqualification policy.

## Answering policy for the chatbot
If the retrieved context does not contain the answer, the chatbot should say that the information is not available and should share the Coders' Club contact details from team/contacts.md. The chatbot should never guess round-wise problem topics, programming languages, exact prize splits, or sponsor contributions.

## Important consistency notes
- CodeX 4.0 is open to II, III and IV year students. The round durations of CodeX 4.0 are not published, so the chatbot must not quote durations from CodeX 3.0 as CodeX 4.0 facts.
- The CodeX 4.0 registration deadline is 23 September 2026.
- Havmor is an ice-cream brand sponsor.
- Financial details of past events (budgets, sponsorship amounts) are deliberately not included.
