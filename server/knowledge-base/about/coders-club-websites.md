## Coders' Club website
The official website of Coders' Club, GPREC is https://www.codersclubgprec.in. The Coders' Club website was launched on 22 August 2024, two days before CodeX 2.0. The launch note explains that a dedicated club website works as a central information hub for the club mission, event schedules (workshops, hackathons, coding competitions), membership details and sign-up. The note lists these benefits: showcasing projects of club members, building a community, attracting new members, giving members web development experience by building and maintaining the site, event registration and announcements, hosting learning resources and coding challenges, networking with other clubs and sponsors, and brand building that can help secure sponsorships.


## CodeX 4.0 registration portal
CodeX 4.0 registration uses a separate portal at https://codex4-0-registration-portal.codersclubgprec.in.
