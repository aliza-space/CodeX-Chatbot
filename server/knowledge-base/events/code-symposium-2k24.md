# Code Symposium 2K24 — Event Report (4 May 2024)

**Category:** event
**Date:** 2024-05-04
**Tags:** Code Symposium, 2K24, individual coding competition, Unstop, programming quiz, winners, Dumont Creamery

## Overview
Code Symposium 2K24 was an individual coding competition organized by Coders' Club, GPREC, on 4 May 2024 from 10:15 AM to 1:00 PM at ECS Lab 3 and ECS Lab 4. The objective of Code Symposium 2K24 was to bring out the problem-solving skills of participants through programming and coding. The event was open to all B.Tech students of GPREC except first-year students.

## Participation in Code Symposium 2K24
- Registered participants: 154. Students who attended: 151.
- Team size: 1 (individual participation).
- Registration fee: ₹50 per individual.
- Platform: Unstop, where participants registered for the contest after paying.

## Format of Code Symposium 2K24
Code Symposium 2K24 had three rounds.
- Round 1: Programming Quiz with 20 questions in 20 minutes, common for all participants.
- Round 2: Coding Round 1 with 1 question in 30 minutes.
- Round 3: Coding Round 2 with 1 question in 60 minutes.
The questions in Rounds 2 and 3 were different for 2nd-year and 3rd-year students to keep the competition fair. Judges assigned marks by speed and accuracy, the marks of all three rounds were added together with the finish time considered, and the top 3 participants by aggregate marks won.

## Prizes of Code Symposium 2K24
1st prize ₹3,000, 2nd prize ₹2,000 and 3rd prize ₹1,000, plus a participation certificate for every participant.

## Winners of Code Symposium 2K24
- 1st prize: Vankam Venkata Durga Prasad (3rd year, CSE).
- 2nd prize: Divite Dinesh (2nd year, CSE AI and ML).
- 3rd prize: Venkata Sankeerth Bandlapalli (3rd year, CSE).
The prize distribution took place near the Amphitheatre on 6 May 2024 at 12:45 PM.
