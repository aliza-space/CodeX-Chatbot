# Code Symposium 2K26 — Event Report (25 March 2026)

**Category:** event
**Date:** 2026-03-25
**Tags:** Code Symposium, 2K26, individual coding competition, Smart Interviews, II year, III year, winners

## Overview
Code Symposium 2K26 was an individual coding competition organized by Coders' Club, GPREC, on 25 March 2026 from 3:30 PM to 5:00 PM in the CSM Labs, in collaboration with Smart Interviews, an edtech platform. The objective of Code Symposium 2K26 was to give students a competitive platform to improve programming, logical thinking and problem-solving skills, and to promote coding culture and technical excellence. Code Symposium 2K26 was open to II-year and III-year students of all branches.

## Participation in Code Symposium 2K26
- Registered participants: 45.
- Team size: individual participation.
- Registration fee: ₹50 per participant.
- Rewards: participation certificates for all participants, and mementos for the winner and runner-up of both the II-year and III-year categories.

## Format of Code Symposium 2K26
Code Symposium 2K26 had two rounds.
- Round 1: Programming Quiz with 20 questions in 20 minutes, testing aptitude, logical thinking and basic coding concepts.
- Round 2: Coding Challenge with 5 programming problems in 90 minutes.
Participants were evaluated on accuracy, logical approach, coding efficiency and successful execution of test cases.
